# External Integrations Specification — Bajaj Enterprises

> **Target Project:** Bajaj Enterprises — Showroom & E-Commerce Platform  

---

## 1. Payment Gateway & Razorpay
- Native test-mode and production-mode Razorpay checkout integration.
- Webhook signature verification (`X-Razorpay-Signature`) via HMAC SHA-256.

---

## 2. Cloudinary Media Storage
- Image upload presets for bicycle catalog photos and user review attachments.

---

## 3. Email & SMS Notifications
- SMTP email confirmation for booking test rides and servicing appointments.
- SMS API gateway triggers for order status milestones.
